04 · Project spotlight

QueryPilot: a text-to-SQL analyst you can audit

  1. 01Natural-language question
  2. 02LLM writes SQL (Gemini or Groq)
  3. 03SELECT-only parser validates
  4. 04Read-only execution
  5. 05On error, feedback and retry
87.5% / 85.0%Gemini, 40 cross-schema Spider questions
80.0% / 80.0%Groq, same benchmark

Problem

LLM-written SQL can be wrong or unsafe, and an analyst you can't audit is hard to trust.

Approach

Validate every query with a SELECT-only parser, execute it read-only, and retry automatically using the error as feedback.

Evaluation

40 cross-schema Spider questions on two LLM providers, so results compare models rather than a single run.

Stack

Python, Gemini API, SQLite, sqlglot, Streamlit, Plotly and Docker.
